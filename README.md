# Modular-adjustable-escapement-mechanism
An adjustable module that contains an escapement mechanism to power things while allowing it's duration between clicks to be adjusted by moving weights towards the center or away from the center of the weight wheel. This would be used for potentially powering something in a controlled manner such as a box lid or unfolding platform. This might not have enough torque to drive mechanisms without intense gearing, but it could help a mechanical circuit as a timer, or maybe even drive weak mechanisms.
